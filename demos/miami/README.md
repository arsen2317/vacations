# Отпуск в Майами

Для презентации скачайте `vacation-miami.html` и откройте его в браузере. Файл работает офлайн.

В календаре видны все 12 месяцев. Чтобы выбрать период через границу года, нажмите на дату начала, переключите год и нажмите на дату окончания. Кнопка «Выбрать целый год» выбирает даты с 1 января по 31 декабря открытого года. На финальном экране «Спасибки» возвращает к началу сценария.

Чтобы пересобрать HTML, выполните из корня репозитория:

```sh
npm ci
node demos/miami/build.mjs
```

Годовая сетка повторяет календарь прототипа. Демо использует его шрифты, иллюстрацию и токены. Оно собирается отдельно от основного приложения.
