# Отпуск в Майами

Для презентации скачайте `vacation-miami.html` и откройте его в браузере. Файл работает офлайн.

Выберите период в календаре или нажмите «Выбрать целый год». На финальном экране «Начать заново» возвращает к началу сценария.

Чтобы пересобрать HTML, выполните из корня репозитория:

```sh
npm ci
node demos/miami/build.mjs
```

Демо использует календарь, шрифты, иллюстрацию и токены из репозитория. Оно собирается отдельно от основного приложения.
