# Техническое описание задачи: редизайн сервиса отпусков

> Версия: 0.2  
> Статус: обновлено по итогам работы над прототипом

---

## 1. Цель

Создать удобный сервис на внутреннем портале, который позволяет:
- планировать ежегодный оплачиваемый отпуск в рамках кампании
- управлять остатком дней отпуска
- подавать заявки на внеплановый отпуск
- согласовывать и отслеживать заявки

Ключевая UX-задача: чётко разграничить сценарии планового и внепланового отпуска, чтобы пользователи понимали, каким путём им нужно идти в каждой конкретной ситуации.

---

## 2. Ключевые сущности

### 2.1 Кампания по планированию отпусков

Кампания — ограниченный по времени период, в течение которого сотрудники распределяют дни ежегодного оплачиваемого отпуска на следующий год.

- Привязана к конкретному году (например, «Кампания 2027»)
- Имеет два состояния: **активна** / **не активна**
- Запускается HR-админом
- Вне активной кампании функция планирования недоступна

**UX-требование:** Пользователь всегда должен чётко понимать, идёт ли кампания сейчас, и какие действия ему доступны в текущем состоянии.

### 2.2 Типы дней отпуска

| Тип | Описание |
|-----|----------|
| Основной ежегодный оплачиваемый | Стандартные 28 дней |
| Дополнительный | 3 дня, есть не у всех сотрудников |
| Накопленный | Дни, перенесённые с прошлых лет |

Баланс отображается раздельно: «18 дней основного отпуска» и «3 дня дополнительного отпуска».

Накопленный остаток прибавляется к основным дням при планировании на следующий год. Суммарно за год можно запланировать не более **40 дней** (включая накопленные).

### 2.3 Типы внеплановых заявок

| Тип | Списываются дни? |
|-----|-----------------|
| Ежегодный оплачиваемый | Да — из баланса основного отпуска |
| Без сохранения зарплаты | Нет |
| Учебный оплачиваемый | Нет |
| Учебный без сохранения зарплаты | Нет |

При выборе типа «Ежегодный оплачиваемый» система валидирует достаточность баланса до отправки. Уход в минус не допускается.

### 2.4 Статусная модель заявки

```
Черновик → На согласовании → На ознакомлении → Согласована
                           → Отклонена
Согласована → Отменена
```

- **Черновик** — создан, не отправлен на согласование
- **На согласовании** — отправлен, ожидает ответа согласующих
- **На ознакомлении** — согласующий одобрил, сотрудник должен подтвердить ознакомление
- **Согласована** — всё подтверждено
- **Отклонена** — хотя бы один согласующий отклонил (комментарий обязателен)
- **Отменена** — сотрудник отменил заявку до её наступления

### 2.5 Согласующие

- **Основной согласующий** — руководитель сотрудника, подставляется автоматически; может быть изменён сотрудником вручную при подаче заявки
- **Дополнительный согласующий** — может быть назначен сотрудником дополнительно при подаче заявки (необязательно)

### 2.6 Подсчёт дней

- Выходные (суббота, воскресенье) **включаются** в дни отпуска
- Государственные праздники **не включаются** в дни отпуска

### 2.7 Накопление дней

За каждый полный месяц работы начисляется **2,33 календарных дня** отпуска. Это значение используется в калькуляторе отпуска.

## 3. Роли пользователей

### 3.1 Сотрудник

#### Главный экран («Работа и отдых»)

Стартовая страница портала, объединяющая несколько блоков в едином виде:

- **Отпуск** — доступный остаток дней, ближайший запланированный отпуск, ссылки на заявки и планирование, напоминание подтвердить план на следующий год
- **График работы** — текущий рабочий график с датой окончания действия, предупреждение об истечении
- **Формат работы** — режим (офис / удалённо / гибрид), расписание по дням недели, процент времени в офисе
- **Командировки** — краткое описание и ссылка на заявки; напоминания (например, сдать отчёт по командировке)

#### Планирование отпуска (в рамках кампании)

- Вкладка «Отпуск» → подвкладка «2027 – планирование»
- Выбирает отрезки отпуска на следующий год в интерфейсе кампании (через год-календарь или диалог добавления периода)
- Видит прогресс-бар распределения дней
- Видит правила планирования (Правила планирования отпуска) во всплывающем модальном окне
- Сохраняет черновик — можно начать и вернуться позже
- Отправляет черновик на согласование

**Ограничения при планировании:**
- Необходимо распределить минимум **28 дней** перед отправкой
- Максимум — **40 дней** суммарно (включая накопленные за прошлые годы)
- Допустимо дробление на части
- Один из отрезков обязан быть не менее **14 дней**
- Кнопка «Отправить на согласование» доступна только когда оба условия выполнены

**Правила планирования, отображаемые пользователю:**
1. Отпуска предоставляются по утверждённому Графику отпусков без отдельных заявлений (ст. 123 ТК РФ)
2. Допускается не более 2 переносов одного периода — не позднее чем за 14 дней до даты его начала
3. Один из отпусков в году должен составить не менее 14 календарных дней
4. Суммарно за год можно запланировать не более 40 дней, включая накопленные за прошлые годы
5. Плановый период нельзя разделить на части. Для более короткого отдыха оформляйте внеплановый отпуск
6. За 10 дней до начала отпуска данные передаются в 1С и формируется отпускной приказ

#### Карточки баланса на странице планирования

На вкладке «Планирование» отображаются три карточки:
- Основной отпуск на год кампании (например, 28 дней)
- Накопленный отпуск
- Распределено (X из Y дней)

#### Работа с согласованным планом

- Может перенести запланированный отрезок:
  - Не позднее чем за **10 дней** до его начала (при наступлении этого порога перенос недоступен)
  - Доступно **2 переноса на один отрезок** (счётчик отображается пользователю)
  - Количество дней нового периода должно **совпадать с текущим** — нельзя взять больше или меньше
  - Перенос требует согласования (создаётся отдельная заявка на перенос)

#### Внеплановые заявки

- Подаёт заявки на внеплановый отпуск (4 типа — см. п. 2.3)
- При подаче:
  - Выбирает период через date picker / выделение в календаре
  - Система показывает предварительное количество дней (праздники не считаются)
  - Система предупреждает о пересечении с отпусками коллег (баннер)
  - Можно оставить комментарий (до 255 символов, необязательно)
  - Можно назначить **заместителя** на период отпуска
  - Можно изменить основного согласующего (по умолчанию — руководитель)
  - Можно добавить дополнительного согласующего (по желанию, через чекбокс)

**Новый сотрудник:** если сотрудник пришёл после старта кампании, он не участвует в ней. Свои дни он может использовать только через подачу внепланового отпуска типа «ежегодный оплачиваемый».

#### Просмотр и управление заявками

- Видит список всех своих заявок на вкладке «Мои отпуска» с сортировкой: предстоящие — сначала, прошедшие — в конце
- Просматривает подробную карточку заявки (модальное окно): тип, период, количество дней, статус, согласующий, дополнительный согласующий, причина отклонения
- Может отозвать заявку в статусе «На согласовании» (до ответа согласующего)
- Может отменить согласованный внеплановый отпуск (до его наступления, автоматически)

#### Калькулятор отпуска

- Доступен с главного экрана сотрудника (иконка рядом с балансом основного отпуска)
- Позволяет выбрать целевую дату и рассчитать, сколько дней отпуска накопится к этой дате
- Расчёт: текущий остаток + 2,33 дня × количество полных месяцев до целевой даты

#### Календарь коллег (вкладка «Коллеги»)

- Два режима просмотра: **год** (временна́я шкала на весь год) и **месяц** (детальный вид по дням)
- Цветовое обозначение: черновик / на согласовании / согласован / пересечения с коллегами
- По умолчанию отображается своя команда
- Можно добавить коллег из других команд через поиск
- Можно удалить коллегу из списка
- Переключатель «Показывать черновики» — включён по умолчанию
- Пересечения своих периодов с периодами коллег выделяются жёлтым; при наведении показывается с кем именно
- Выбор отображаемого года (текущий и следующий)
- При просмотре плановых отрезков (год кампании) на диаграмме отображаются черновики из текущего плана пользователя

#### Просмотр пересечений на главном экране

- Раздел «Пересечения» под списком отпусков
- Показывает коллег из той же команды, у которых есть согласованные или ожидающие отпуска
- Можно добавить дополнительных коллег для отслеживания

---

### 3.2 Руководитель

Всё то же, что у сотрудника, плюс:

#### Входящие заявки на согласование (вкладка «Команда»)

Два режима просмотра:
- **Таблица** — колонки: № заявки, сотрудник, подразделение, период отпуска, статус, действия
- **График** — временна́я шкала на год кампании по сотрудникам (цвета по статусам, пересечения выделены)

Фильтры:
- Поиск по ФИО/должности/подразделению
- Фильтр по подразделению
- Фильтр по типу заявки (плановый / внеплановый)
- Фильтр по году

Действия:
- Согласовать или отклонить заявку — из таблицы (кнопка «···») или из карточки заявки
- При отклонении — комментарий с причиной обязателен
- При просмотре карточки — видит баннеры о пересечении с другими сотрудниками

#### Отчётность

- Просматривает статистику по кампании: всего заявок, на согласовании, согласованы, без плана отпуска
- Выгружает отчёт по заявкам подчинённых в формате **CSV** (сотрудник, подразделение, должность, период, статус)

---

### 3.3 HR-админ

Всё то же, что у сотрудника, плюс:

#### Управление кампанией (вкладка «HR-панель»)

- Просматривает статус кампании: активна / не активна
- Видит статистику по всей компании:
  - Всего сотрудников
  - Согласованы
  - На согласовании
  - Черновики
- Прогресс-бар согласования (зелёный — согласованы, жёлтый — на согласовании)
- Выгружает отчёт в формате CSV

## 4. UI / UX-требования

### 4.1 Навигация

Разделы разбиты по вкладкам:
- **Работа и отдых** — стартовая страница (обзор)
- **Отпуск** — главная вкладка сотрудника с подвкладками по годам
- **Планирование** — планирование отпуска в рамках кампании
- **Коллеги** — календарь отпусков коллег
- **Команда** — входящие заявки (только для руководителя и HR-админа)
- **HR-панель** — управление кампанией (только для HR-админа)

### 4.2 Отображение отрезков отпуска

Плановые отрезки отображаются в двух видах одновременно:
- **Список** (левая панель) — с датами, количеством дней, статусом и кнопкой удаления (в черновике)
- **Год-календарь** (правая панель) — визуальное отображение с цветами по статусу

### 4.3 Флоу планирования

- Поддерживает два пути: распланировать всё сразу и отправить; начать, сохранить черновик, вернуться позже
- Кнопка «Отправить на согласование» доступна только когда выполнены оба условия: ≥ 28 дней распределено и есть отрезок ≥ 14 дней
- Прогресс-бар с подписью «X из Y дней распределено»
- Условия показаны как баннеры: зелёный (Done) = условие выполнено, красный (Danger) = условие не выполнено
- Перед отправкой: модальное окно подтверждения со списком отрезков, отображением согласующего и возможностью добавить дополнительного согласующего

### 4.4 Разграничение планового и внепланового

Ключевая UX-задача: через подсказки, контекстные объяснения и чёткое разделение сценариев в интерфейсе.

### 4.5 Статус кампании

Пользователь всегда видит, идёт ли кампания сейчас. Интерфейс адаптируется: активна / не активна.

### 4.6 Overlap detection (пересечения)

Система выявляет пересечения отпусков и информирует пользователей на нескольких уровнях:
- При создании внеплановой заявки — баннер «Период пересекается с [Имя]: [даты]»
- На главном экране в год-календаре — жёлтые метки на днях пересечений
- На вкладке «Планирование» в диаграмме Ганта — черновые отрезки, пересекающиеся с коллегами, выделены жёлтым
- На вкладке «Коллеги» — аналогичная логика в год- и месяц-диаграммах
- В карточке заявки (руководитель) — баннеры о пересечении с другими сотрудниками

### 4.7 Ганtt-диаграмма коллег на странице планирования

На вкладке «Планирование» — отдельная карточка «Планы отпуска коллег» (Gantt) с:
- Поиском сотрудников для добавления в список
- Выбором отображаемого года (текущий / год кампании)
- Навигацией по полугодиям (стрелки ←→ по месяцу)
- Переключателями «Показывать черновики» и «Показывать пересечения»
- Цветовой легендой
- Тултипами при наведении: даты, статус, список пересекающихся коллег

## 5. За скоупом (текущая итерация)

- Уведомления (email, push, in-app)
- Сценарий исчерпания лимита переносов
- Редактирование согласованного плана после исчерпания переносов
- Сотрудники с нестандартными графиками / неполной ставкой
- Декабрьская опция HR-админа (разрешить отмену плановых отпусков до 31 декабря)
- Запуск кампании HR-админом (в прототипе кампания задаётся через mockData)
- Подтверждение ознакомления со стороны сотрудника (статус «На ознакомлении» присутствует в системе, но флоу не реализован)
- Роль «Техническая поддержка»
- Роль «Отпуска: просмотр статистики»
